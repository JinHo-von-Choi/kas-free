# 카-스 프리 (Kas-Free)

디시인사이드 게시글의 이미지를 검사하고 위험·주의·미확인 상태를 표시하는 Chrome Manifest V3 확장 프로그램입니다. 알려진 이미지 해시를 NSFWserver에서 조회하고, 사용자 선택에 따라 서버 이미지 검사 또는 직접 설정한 AI 제공자의 재검증을 사용합니다.

## 설치

Chrome 116 이상에서 이 저장소를 내려받고 `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드로 저장소 폴더를 선택합니다. 변경 후 확장을 다시 로드하고 열린 디시 페이지를 새로 고칩니다. Node는 개발·시험에만 필요합니다.

## 보호 동작

- 기본값은 미확인 본문 이미지 가림, 자동 선행 조회 끄기, 서버 원본 업로드 끄기입니다. 직접 공개하거나 재검사할 수 있습니다.
- 해시 미일치는 **미확인**입니다. 취소·시간 초과·통신 오류를 정상 판정으로 바꾸지 않습니다. 여러 이미지가 있는 글은 본문 이미지 전체 결과를 합칩니다.
- 설정에서 10개 범주의 적용 여부, 도메인 예외, 일시 해제, 민감도, 서버 원본 업로드와 선행 조회를 관리합니다. 서버의 개인 정책 결과를 유지합니다.
- 판정 버전을 확인할 수 있으면 변경 시 공개한 이미지도 다시 검사합니다. 조회 API가 없으면 정상 판정은 60초 후 미확인으로 돌려 화면을 가리고 직접 재검사를 기다립니다.
- 이미지는 사이트 DOM과 네트워크에서 제거되지 않습니다. 가림은 화면 노출 제어이며 디시 페이지 자체의 이미지 다운로드까지 중단하는 기능은 아닙니다.

## 디시 요청 제한

확장이 추가하는 게시글·이미지 다운로드는 모든 탭이 하나의 요청 브로커를 공유합니다. 최소 시작 간격은 1.5초, 전체 예산은 분당 30회·시간당 240회입니다. 게시글 HTML은 분당 12회·시간당 120회로 더 제한합니다. 대기열은 20개, 탭당 구독은 5개입니다. 예산을 먼저 저장한 뒤 전송하므로 확장 재시작으로 사용량이 초기화되지 않습니다.

동일 주소의 대기 요청을 합치고 HTML 60초·이미지 30초의 짧은 메모리 캐시를 사용합니다. HTML은 2MiB, 이미지는 10MiB를 넘으면 중단합니다. 429는 `Retry-After`까지 대기하고 401·403·차단 안내는 자동 조회를 중단합니다. 설정의 재개 버튼도 남은 예산과 대기 시간을 우회하지 않습니다. 이 수치는 보수적인 기본 제한이며 사이트 차단 방지를 보장하지 않습니다.

## 서버 연동

기본 서버는 `https://nsfw.nerdvana.kr`입니다. 해시는 dHash·aHash를 생성하며 구현하지 않은 pHash를 dHash로 가장하지 않습니다. 서버 이미지 검사를 허용하면 같은 다운로드의 원본 바이트를 전송합니다. 서버의 CLIP·MiniMax 모델이나 인증 정책을 변경하지 않습니다.

연결 서버 소스의 `/api/policy/revision` 조회 경로를 추가했습니다. **소스 변경이며 운영 배포는 수행하지 않았습니다.** 이 경로가 없는 서버에서도 기본 검사는 동작하지만 판정 버전에 따른 캐시 재사용은 비활성화됩니다.

AI 재검증에는 해당 제공자의 유효한 API 키가 필요하며 유료 호출이 발생할 수 있습니다. 제공자가 폐기한 모델은 오류를 표시합니다. 응답 필드·점수가 잘못되면 안전 기본값을 만들지 않고 판정을 보류합니다.

## 데이터와 보안

API 키는 확장 로컬 저장소에 저장하며 콘텐츠 스크립트에는 전달하지 않습니다. 로컬 저장소 접근은 확장의 신뢰 컨텍스트로 제한합니다. 키는 서버·AI 제공자의 인증에 사용되므로 해당 요청의 인증 헤더로 전송됩니다. 저장 시 암호화하는 기능은 없습니다.

일반 검사에서 이미지 해시, 게시글 주소, 익명 reporter ID와 개인 정책이 서버로 전달될 수 있습니다. 원본 서버 검사 허용 시 이미지 바이트가 서버로 전달되고, AI 재검증은 이미지와 프롬프트를 선택한 제공자에 전달합니다. 신고·화이트리스트 요청은 이미지 주소와 사유 등을 전송합니다. 추가 다운로드는 HTTPS 디시 주소만 허용하며 리디렉션·임의 내부 주소를 거부합니다. 상세 개인정보 정책은 [서버 개인정보 정책](https://nsfw.nerdvana.kr/privacy)을 확인하세요.

## 개발과 검증

Node 22 이상에서 실행합니다.

```bash
npm ci
npm test -- --runInBand
npm run test:e2e
```

이미 설치된 Chromium을 사용하려면 `CHROME_BIN=/절대/경로/chrome npm run test:e2e`로 지정합니다. E2E는 실제 확장을 Chrome에서 로드하며 디시·서버·유료 AI 네트워크를 시험 자료로 대체합니다. 실제 디시를 반복 수집하거나 유료 API를 호출하지 않습니다. 자세한 설명은 [시험 가이드](tests/README.md)를 참조하세요.

연구 계획·구현 상세 문서는 로컬 `docs/`에 보관하며 Git과 릴리즈에서 제외합니다. 릴리즈 변경 사항은 [CHANGELOG](CHANGELOG.md)를 확인하세요. 실제 라벨 자료를 이용한 정확도·누락률 평가와 신규 모델 채택은 아직 완료하지 않았습니다. 시험 자료의 통과를 실사용 탐지 정확도로 해석하지 않습니다.
