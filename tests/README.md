# 시험 가이드

Node 22 이상과 Chrome 116 이상이 필요합니다. `npm ci`로 잠금 파일에 맞는 개발 의존성을 설치합니다.

```bash
npm test -- --runInBand
npm run test:e2e
```

단위 검사는 Jest 30, 브라우저 검사는 Node의 기본 시험 실행기와 Puppeteer를 사용합니다. `jest-chrome`은 사용하지 않습니다. Puppeteer가 설치한 브라우저 대신 기존 Chromium을 지정할 수 있습니다.

```bash
CHROME_BIN=/절대/경로/chrome npm run test:e2e
```

E2E는 실제 확장 service worker, 옵션 페이지, 콘텐츠 스크립트를 로드합니다. CDP와 페이지 요청 가로채기로 외부 요청을 통제하므로 실제 디시 반복 조회, 서버 쓰기, 유료 AI 호출이 없습니다. 비민감 PNG 자료는 `tests/fixtures/marker.png`입니다. 브라우저 검사는 같은 세션·상태를 공유하므로 순차 실행합니다.

핵심 인수 조건은 요청 간격·전체 예산·429 대기·재시작 상태, 다중 이미지의 미확인 보호·직접 공개·동적 변경, 서버 개인 범주 정책, 판정 버전 변경 재검사, 메시지 권한·키 접근 차단입니다. 단위 검사는 브로커의 저장 실패·시계 역행·크기 제한·탭 취소와 실제 응답 정규화·개인 정책을 검사합니다. 제공자 경계 검사는 불완전한 AI 응답이 안전으로 보정되지 않는지 확인합니다.

커버리지 보고는 `npm run test:coverage`로 생성할 수 있습니다. 기존 전체 커버리지 기준의 충족을 이번 변경의 완료 조건으로 주장하지 않습니다. 실제 사용자 자료의 정확도, 대규모 부하, 실제 사이트의 차단 임계값은 이 시험으로 검증되지 않습니다.
